# Versão simples (vanilla) do site

Esta pasta contém uma versão simplificada do site implementada com HTML, CSS e JavaScript puro.

Como testar localmente:

1. No terminal, rode um servidor estático (ex.: `npx serve` ou `npx http-server`):

```bash
cd site/vanilla
npx serve
```

2. Abra o navegador em `http://localhost:5000` (ou outra porta informada pelo servidor).
